# rdpMini

■■ An Windows PC App for Remotely Accessing a Server PC from a Client PC

-  Imitate the functionality of [AnyDesk] or [Google Remote Desktop].
1. Download all the files provided here to both the server PC and the client PC.
2. On the server PC, double-click rdp_server.bat to run it.
3. On the client PC, double-click rdp_client.bat to run it. However, before running it, open the file in Notepad and modify only the server's IP address as appropriate.


■■  client PC에서 server PC를 원격 접속하는 Windows PC 앱

ㅡ  [ AnyDesk ] 또는 [ Google Remote Desktop ] 기능 흉내내기
1) 여기에 있는 모든 파일들을  서버PC와 클라이언트PC에  각각 다운로드
2) 서버PC에서는  rdp_server.bat 를 클릭 실행.
3) 클라이언트PC에서는 rdp_client.bat 를 클릭 실행.  단, 실행전에 이 파일을 메모장으로 열어서, 서버 IP주소만 적절하게 수정
